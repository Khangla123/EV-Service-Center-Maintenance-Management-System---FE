## Welcome to SWP391 Repository

### You will find in this repo the following stuff

* A comprehensive EV service center management system with modern React frontend
* Implementation of a multi-role user management system with authentication
* Service appointment booking and maintenance tracking functionality
* VinFast-inspired UI/UX design with responsive layout

### Technologies used

* React 18 with TypeScript
* React Router Dom for navigation
* Material Design components
* Lucide React for icons
* CSS3 with responsive design
* Context API for state management

### API Features

* User authentication and role-based access control
* Appointment booking and management system
* Vehicle maintenance tracking and history
* Real-time service status updates
* Multi-role dashboard (Customer, Staff, Technician, Admin)
